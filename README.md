# Trend Miner

Trend Miner é um analisador de tendências baseado em texto.

Ele coleta títulos de conteúdo e detecta quais termos estão emergindo ao comparar períodos diferentes.

## Funcionalidades

- limpeza de texto
- tokenização
- análise de frequência
- detecção de tendências
- geração de relatório

## Estrutura

trend-miner/
- collectors
- processing
- analysis
- reports
